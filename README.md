## 🛠 Установка (Windows / Steam Deck / Linux) - за 30 секунд

1. Полностью закройте игру, если она запущена.
2. В библиотеке Steam нажмите правой кнопкой мыши по **Melvor Idle 2** → **Управление** → **Просмотреть локальные файлы**.
3. Распакуйте содержимое архива (`override.cfg` и папку `mod`) прямо в открывшуюся папку с игрой (рядом с `Melvor2.exe`).
4. Проверьте, чтобы структура выглядела так:
   ```text
   Melvor Idle 2/
   ├── Melvor2.exe
   ├── override.cfg
   ├── mod/
   │   ├── ru.po
   │   └── ru_patch.gd
   └── data_GamesByMalcs.Melvor2_windows_x86_64/
   ```
5. Запустите игру через Steam и выберите **«Русский»** при первом запуске (либо в меню **Settings → Language → Русский**).

---

## 🗑 Удаление

Удалите файл `override.cfg` и папку `mod` из папки с игрой - игра мгновенно вернётся к чистой английской версии без перекачивания файлов.
